This is a sample MD File. You can use Markdown syntax to format your text, create lists, add links, and more. Here are some examples:

 1. **Bold Text**: Use double asterisks or double underscores to make text bold. For example, `**bold**` or `__bold__` will render as **bold**.
 2. *Italic Text*: Use single asterisks or single underscores to italicize text. For example, `*italic*` or `_italic_` will render as *italic*.
 3. [Links](https://www.example.com): You can create hyperlinks using square brackets for the text and parentheses for the URL. For example, `[Example](https://www.example.com)` will render as [Example](https://www.example.com).
